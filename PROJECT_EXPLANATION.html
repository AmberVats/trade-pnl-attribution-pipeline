Ingestion & Validation ⚙️

Validates raw CSV columns, enforces referential foreign keys against instrument masters, and leverages PostgreSQL ON CONFLICT DO UPDATE for idempotent batch loads.

Weighted-Average Engine 📊

Replays BUY and SELL events in sequence. Dynamically recalculates weighted average unit cost on acquisitions and retains cost basis on partial position liquidations.

Attribution & Reporting 📈

Deconstructs total PnL into Realized (execution alpha) and Unrealized (overnight price shift). Exposes standard SQL views and compiles an executive visual dashboard.

4 Mathematical & Financial Attribution Mechanics

Exact mathematical specifications used across all calculation layers.

1. Weighted Average Cost (BUY)
$$\bar{P}_{\text{new}} = \frac{(Q_{\text{old}} \times \bar{P}_{\text{old}}) + (Q_{\text{buy}} \times P_{\text{buy}})}{Q_{\text{old}} + Q_{\text{buy}}}$$

Increases quantity and blends execution price into unit cost basis.

2. Position Reduction (SELL)
$$Q_{\text{new}} = Q_{\text{old}} - Q_{\text{sell}}, \quad \bar{P}_{\text{new}} = \bar{P}_{\text{old}}$$

Cost basis per unit remains unchanged on partial sales.

3. Realized PnL (Closed Trade)
$$\text{Realized PnL} = Q_{\text{sold}} \times (P_{\text{sell}} - \bar{P}_{\text{cost}})$$

Profit crystallized upon selling inventory above weighted average cost.

4. Unrealized PnL (Mark-to-Market)
$$\text{Unrealized PnL} = Q_{\text{closing}} \times (P_{\text{market close}} - \bar{P}_{\text{cost}})$$

Valuation gain/loss on remaining open inventory at day-end close.

7 Operations & Reproduction Runbook

Commands to reproduce the pipeline from scratch on any workstation.

PowerShell · Complete Lifecycle Runbook 
# 1. Clone repository and setup environment
git clone https://github.com/AmberVats/trade-pnl-attribution-pipeline.git
cd trade-pnl-attribution-pipeline
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 2. Launch PostgreSQL 16 container
docker compose up -d

# 3. Apply Schema DDL & Analytical Views
Get-Content sql\01_schema.sql | docker exec -i trade_pnl_postgres psql -U trade_user -d trade_pnl
Get-Content sql\02_views.sql | docker exec -i trade_pnl_postgres psql -U trade_user -d trade_pnl

# 4. Execute Full Pipeline (Loads data, builds positions, computes PnL & outputs HTML report)
python -m src.pipeline

# 5. Run Automated Tests
python -m pytest -v
